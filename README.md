# Insurance ML API

Proyecto académico desarrollado durante mi formación en Data Science.

## Objetivo
Desarrollar un modelo de Machine Learning orientado a estimar primas de seguros y exponer las predicciones mediante una API.

## Metodología
- Preparación y procesamiento de datos.
- Entrenamiento del modelo de Machine Learning.
- Integración del modelo en una API.
- Uso de FastAPI para exponer predicciones.
- Integración con SQL para manejo de información.

## Herramientas
- Python
- Machine Learning
- FastAPI
- SQL
- Jupyter Notebook

## Resultados
El repositorio contiene el modelo, notebooks y archivos necesarios para la implementación de la API.

## Limitaciones
Proyecto académico orientado al aprendizaje de integración entre Machine Learning y APIs.
